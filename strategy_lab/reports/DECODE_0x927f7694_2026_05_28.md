## Direction Rule

**Dominant predictor:** `cl_basis_bps` (Binance BTC spot price vs Chainlink strike at entry, in bps).

- Low cl_basis (<16 bps) → wallet buys **Up** 63% of the time
- High cl_basis (≥16 bps) → wallet buys **Down** 63% of the time
- Interpretation: when Binance is only slightly above chainlink strike (low basis), there's room to run Up; when Binance has already run above strike substantially (high basis), Down is favored.

**Direction agreement stats:**

| cl_basis threshold | Agreement with held_side |

| Median (14.4 bps) | 61.1% |

Direction is imperfect (65%) — the wallet uses additional signal we can't fully observe. `utc_hour` adds marginal discrimination (Up fires average 13.4h UTC vs Down at 11.3h). Combined cl_basis + hour rules don't substantially exceed 65%.

**Direction × WR (identical structure for Up and Down):**
The WR-by-entry-px pattern is symmetric: both Up and Down fires show near-100% WR above 0.60 entry. This confirms the edge is in correct-side selection, not in any directional bias.

1. **Entry filter: px ≥ 0.50** (book-observable at fire time) — trivial

### Risks / gaps:
1. **Direction is 65% — not 80%+.** Cannot fully reconstruct direction rule from canonical features. Wallet has a signal we can't see (possibly orderflow, MEV, or OTC information).
2. **57 contrarian fires are unexplained drag.** If deployed mimicking the wallet, these would hurt. Need explicit px≥0.50 filter.
3. **Slug selection is near-random** — no cherry-picking signal to copy.
4. **WR inflated by late-slug entries** (market-favored side at 0.70+ is near-certain; buying at 0.80 for $10 to win $2 is low-EV absolute dollar).

### Verdict: **MEDIUM deployability**
- The edge is real and reproducible IF filtered to px≥0.50 + rv<4 + within-60s entry
- Direction rule (65% accuracy via cl_basis) is partially replicable — marginal but positive
- Pure "buy the favorite when RV is low" is a viable systematic strategy
- Recommend: gate on px ≥ 0.55, rv_15m < 4, fire_offset_s ≤ 90, use cl_basis < 16 for direction
